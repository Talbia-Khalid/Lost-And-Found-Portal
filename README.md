✦ Lost And Found Portal

A web-based Lost and Found Management System developed using C# and Blazor.

📌 About the Project

Lost And Found Portal is designed to provide a simple platform where users can report lost belongings and help others find missing items.

✨ Key Features

- Report lost items.
- Report found items.
- Browse submitted reports.
- Help connect lost belongings with their owners.

🛠️ Technologies Used

- C#
- Blazor
- .NET
- HTML
- CSS
- SQL Server / Database (confirm the actual database before keeping this)

🚀 Project Purpose

The purpose of this project is to make the process of reporting and finding lost belongings easier through a centralized digital platform.
